## Інформація

### Що таке предметно-орієнтована мова?

*Предметно-орієнтована мова* (англ. _**D**omain **S**pecific **L**anguage, **DSL**_) є мовою програмування або специфікації, яка спеціально розроблена для ефективного вирішення **вузького кола задач**, типових для певної **[[Інженерія домену. Концепція#^1d469b|предметної області (домену)]]**.

Вона надає **специфічну семантику** та **виразні синтаксичні конструкції**, що спрощує роботу саме з проблемами, характерними для цільового домену.

### Ключові особливості DSL

Особливості DSL пов'язані саме з її **фокусуванням на конкретній предметній області** (наприклад, фінансові розрахунки, конфігурація обладнання, графічні макети):

- **Оптимізація** — DSL **оптимізована** для вирішення *саме доменних задач*, ігноруючи загальні обчислювальні завдання.    
- **Обмеженість** та **Потужність** — DSL зазвичай має **обмежений набір лінгвістичних конструкцій** порівняно з мовами загального призначення (General-Purpose Languages, GPL). Ця обмеженість, парадоксально, забезпечує її більшу **зрозумілість** та **потужність** при вирішенні саме доменних проблем.

### Реалізація DSL

Предметно-орієнтовані мови можуть бути реалізовані двома основними способами:

1. **Внутрішні (Internal / Embedded) DSL**  — реалізовані як **бібліотека, API або синтаксична надбудова** у мові програмування загального призначення (*англ.* [_**G**eneral **P**urpose **L**anguae, **GPL**_](https://en.wikipedia.org/wiki/General-purpose_programming_language)), наприклад, спеціалізовані бібліотеки на Python або методи у Ruby/Scala, які імітують доменну мову.
2. **Зовнішні (External / Standalone) DSL** — повністю **окремі мови** зі своїм власним парсером, компілятором або інтерпретатором (наприклад, [HTML](https://uk.wikipedia.org/wiki/HTML), [SQL](https://uk.wikipedia.org/wiki/SQL), [G-Code](https://uk.wikipedia.org/wiki/G-code)). ^a072b0

### Переваги Використання DSL

Основна перевага DSL полягає в тому, що вони дозволяють *представляти концепції та правила домену більш природним способом*, який є *зрозумілим для експертів* цієї предметної області (*Domain Experts*), навіть якщо вони не є професійними розробниками.

Таке сфокусоване представлення забезпечує:

- **Покращену комунікацію** — спрощує спілкування та співпрацю між **експертами домену** та **розробниками** програмного забезпечення.    
- **Підвищення продуктивності** — зменшує обсяг програмування (boilerplate code) і дозволяє експертам самостійно вносити зміни.    
- **Зменшення кількості помилок** — завдяки природним для предметної області **ідіоматичним конструкціям** та обмеженому синтаксису, ризик внесення логічних помилок зменшується.    
- **Підвищення рівня абстракції** — абстрагує експерта від складнощів реалізації, дозволяючи йому зосередитися виключно на бізнес-логіці.

### Приклади популярних DSL

|   DSL    | Повна назва               | Предметна область                                      | Призначення                                                                                                            |
| :------: | ------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
|  *SQL*   | Structured Query Language | Управління реляційними БД                              | Створення, читання, оновлення та видалення даних у базах.<br/>Оптимізована виключно для маніпулювання даними           |
|  *HTML*  | Hypertext Markup Language | Веб-розробка                                           | Мова розмітки, що визначає **структуру та контент** веб-сторінок за допомогою спеціальних тегів                        |
| *LaTeX*  |                           | Академічна та технічна верстка                         | Система підготовки документів для високоякісного форматування тексту, таблиць, складних математичних формул та графіки |
| *MATLAB* | Matrix Laboratory         | Чисельні обчислення та моделювання                     | Мова та інтегроване середовище для матричних операцій, обробки сигналів, моделювання систем та візуалізації даних      |
|   *R*    |                           | Статистичний аналіз та наука про дані (*Data Science*) | Мова та середовище для статистичних обчислень, розв'язання статистичних задач та побудови графіків                     |
| *G-Code* | Geometric Code            | Комп'ютерне Числове Керування (ЧПК)                    | Мова команд для керування рухом робочих органів верстатів, 3D-принтерів та іншого промислового обладнання              |
